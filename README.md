# NumPy for AI/ML

This repository contains NumPy practice programs and fundamental operations used in Artificial Intelligence, Machine Learning, and Data Science.

## Topics Covered

- NumPy Array Creation
- Array Attributes
- Indexing
- Slicing
- Reshaping
- Zeros and Ones
- arange()
- Arithmetic Operations
- Statistical Operations
- Matrix Operations
- Random Arrays
- Sorting

## Purpose

The purpose of this repository is to build a strong foundation in NumPy before learning Pandas, Data Visualization, and Machine Learning.
